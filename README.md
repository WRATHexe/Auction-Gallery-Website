# Auction Gallery

Welcome to the **Auction Gallery** project! This is an interactive platform where users can explore and participate in auctions for unique and valuable items.

🌐 **Live Site**: [Visit Auction Gallery](https://wrath-auction-gallery.netlify.app/)

---

## 🚀 Features

- 🖼️ **Browse Items**: Explore a wide range of auction items with detailed descriptions and images.  
- ⏳ **Real-Time Auctions**: Participate in live auctions with countdown timers.  
- 📈 **Dynamic Bidding**: Place bids and see real-time updates on the highest bid.  

---

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript  
- **Framework**: React.js 
- **Hosting**: Netlify  

---

## 📋 How to Run Locally

1. Clone the repository:  
    ```bash
    git clone https://github.com/your-username/auction-gallery.git
    cd auction-gallery
    ```

2. Install dependencies:  
    ```bash
    npm install
    ```

3. Start the development server:  
    ```bash
    npm start
    ```

4. Open your browser and navigate to `http://localhost:3000`.
